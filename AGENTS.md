# Royal Chaska Dubai — Codebase Guide

This repository contains the official production website for **Royal Chaska**, an Indian & Indo-Chinese restaurant located in Al Karama, Dubai.

## Verified Restaurant Data

- **Name**: Royal Chaska
- **Address**: Shop 97, Sheikh Khalifa Bin Zayed St, Beside President Hotel, Al Karama, Dubai, UAE
- **Phone**: +971 56 830 6501
- **Google Maps**: https://maps.app.goo.gl/i1ansFFmvXWMU8vm6
- **Cuisine**: Indian / Indo-Chinese
- **Price Range**: AED 1–50

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS / Vanilla CSS with Royal Purple (`#4B164C`), Burgundy (`#2A0E24`), and Antique Gold (`#C9A227`) design system.
- **Icons**: Lucide React
- **Animations**: Motion (framer-motion)
