# Royal Chaska Dubai

Official modern responsive website for **Royal Chaska Dubai**, located at Shop 97, Sheikh Khalifa Bin Zayed St, beside President Hotel, Al Karama, Dubai, UAE.

## Features

- **Next.js 15 App Router**: High performance static generation & SEO.
- **Direct WhatsApp Ordering**: One-click direct order redirection (`+971 56 830 6501`).
- **Dedicated Subpages**:
  - `/menu`: Sizzling tandoori grills, handi dum biryanis, Peshawari karahi, butter chicken, rolls, and falooda.
  - `/story`: Charcoal tandoor heritage and late-night dining story.
  - `/reviews`: Filterable verified Google reviews and metrics.
  - `/gallery`: Categorized high-resolution photo gallery with interactive lightbox dialog.
  - `/location`: Live Dubai time status, Google Maps embed, and transit guide beside President Hotel.
- **Tailwind CSS & Framer Motion**: Sleek dark/warm palette with micro-animations.

## Getting Started

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```
